# Teaching ITC
We will use the slides of the course **Practical Programming in C** from MIT OCW. Use the link below:
- https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/

Relevant slides with page numbers:
- C introduction: Lecture 1, pages 1-6
- Variables, data types, constants, operations, type conversion: Lecture 2, pages 1-7, 10-25
- Input/Output or I/O: Lecture 4, pages 8-16, 19, 20
- Loops, conditions, and scope, Lecture 3, pages 1-24, 38-40
- Arrays, Lecture 5, pages 15, 18-20, Lecture 7, page 13
- Functions, Lecture 1, pages 25-28
